1. `01_표지.png` — 대표 이미지
2. `02_시스템맵.png` — 데이터가 들어와서 결과가 나가는 전체 구조
3. `03_구축사례.png` — 직접 구축한 시스템 6종
4. `04_주문취합.png` — 사례 1: 주문 취합 → 택배 엑셀 · 구글 시트
5. `05_전용웹사이트.png` — 사례 2: 전용 관리 웹사이트
6. `06_가능한자동화.png` — 업종별로 만들 수 있는 자동화
7. `07_진행방식.png` — 진행 순서, 사용 도구, 받으시는 것

## 포트폴리오 제목
업무자동화 · CRM · DB 구축 대표 포트폴리오 (n8n · AI · 전용 관리 웹사이트)

## 설명
주문 취합, 엑셀 정리, 고객 관리, 매출 집계처럼 매일 손으로 하는 일을 자동화하고, 우리 회사만의 관리 화면으로 만들어 드립니다.

- n8n 워크플로: 스마트스토어·쿠팡 주문 취합, 택배 업로드 엑셀과 구글 시트 자동 생성, 새 주문 알림, 일일 매출 리포트
- AI 연동: 고객 문의 분류와 답변 초안, 의뢰 내용 분석과 견적 초안
- 전용 웹사이트: 통합 주문·정기배송 CRM, 계약·매출 DB, 매출관리 시스템, 자동화 운영 콘솔

화면의 업체명과 금액은 예시 데이터입니다.

## 다시 만들기
`slides.html`을 고친 뒤 `node docs/portfolio/00_대표/render.js` 를 실행하면 7장이 다시 만들어집니다.

## n8n 화면 버전 (4장)

실제 n8n 편집 화면에서 캡처한 시스템 맵입니다.

- `n8n_00_전체맵.png` — 자동화 6종을 한 캔버스에
- `n8n_01_주문_알림.png` — ① 주문 취합 → 택배 엑셀·구글 시트, ② 새 주문 알림
- `n8n_02_AI_리포트.png` — ③ 고객 문의 AI 답변 초안, ④ 일일 매출 리포트
- `n8n_03_견적_CRM.png` — ⑤ 의뢰 분석 → 견적·계약 DB, ⑥ 통합 CRM·정기배송 동기화

맵 워크플로(`n8n/map_*.json`)는 구조를 보여주는 용도라 그대로 실행되지는 않습니다. 실제로 동작하는 워크플로는 `workflows/` 폴더에 있습니다.
다시 만들기: `python3 docs/portfolio/00_대표/n8n/build_map.py` → n8n에 가져오기(import) → `n8n/shots.js`로 캡처

## 글로우 스타일 (7장)

어두운 격자 위에 빛나는 연결선으로 그린 시스템 맵입니다 (`glow/`).

- `glow_00_전체맵.png` — 들어오는 곳 → AI 자동화 엔진 → 결과
- `glow_01_주문취합.png` ~ `glow_06_CRM동기화.png` — 시스템별 1장씩

다시 만들기: `glow/glow.html`의 장면(S)을 고친 뒤 `node docs/portfolio/00_대표/glow/render.js`
