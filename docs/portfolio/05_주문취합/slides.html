실제 운영에서 생기는 일까지 처리합니다

  • 판매처를 넘나드는 합포장스마트스토어와 쿠팡에서 같은 집으로 간 주문을 한 박스로

  • 주말 주문 누락 방지월요일은 주말 포함 조회, 24시간 제한 API는 구간을 나눠 조회
