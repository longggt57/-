## 설명 (붙여넣기용)

**어떤 문제였나**
스마트스토어와 쿠팡을 함께 운영하는 셀러는 매일 아침 두 판매처의 주문 엑셀을 따로 내려받습니다. 그다음 열 순서를 맞춰 합치고, 택배사 양식에 받는 분·주소·품목을 다시 옮겨야 합니다. 하루 50건 기준으로 약 40분이 걸리고, 옮기는 과정에서 옵션이나 주소가 틀려 오배송이 생깁니다.

**무엇을 만들었나**
출고일 아침 8시 40분에 자동으로 실행되는 n8n 워크플로입니다.
1. 스마트스토어(커머스 API)와 쿠팡(Wing Open API)의 새 결제 주문을 직접 가져옵니다.
2. 이미 처리한 주문은 빼고, 받는 분·연락처·주소가 이상한 주문은 '확인필요'로 따로 분리합니다.
3. 판매처가 달라도 같은 집으로 가는 주문은 한 박스로 합칩니다.
4. 구글 스프레드시트를 새로 만들어 탭 3개(택배업로드 · 주문전체 · 확인필요)에 정리합니다. 머리글 고정, 열 너비 자동 조정, 원하는 드라이브 폴더 저장까지 됩니다.
5. 택배사 업로드 양식의 엑셀 파일을 만듭니다.
6. 시트 링크와 엑셀 첨부를 메일로 보내고, 슬랙으로 요약을 알립니다.

**신경 쓴 부분**
- 네이버 주문 조회 API는 한 번에 24시간까지만 조회됩니다. 그래서 구간을 나눠 조회하고, 월요일에는 주말 주문까지 포함합니다.
- 쿠팡 안심번호(0503)도 정상 번호로 인식합니다. 합포장할 때는 실제 번호가 있으면 그 번호를 씁니다.
- 메일 발송까지 성공한 주문만 '처리 완료'로 기록합니다. 중간에 실패하면 다음 실행 때 다시 포함됩니다.
- 택배사 양식은 설정 칸에 "엑셀열=항목"을 한 줄씩 적어 바꿉니다. 코딩 없이 수정할 수 있습니다.
- 판매처 API 키를 비워 두면 그 판매처는 건너뜁니다. 스마트스토어만 운영하는 셀러도 그대로 쓸 수 있습니다.

**결과**
아침 주문 정리가 '메일 열고 엑셀 업로드'만으로 끝납니다. 하루 50건 기준 예시로 약 40분이 확인 시간만 남게 줄어듭니다.

※ 이미지 속 주문 데이터는 모두 가상의 예시입니다.
