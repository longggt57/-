# 마케팅 전략 — 쇼핑몰 셀러 자동화

## 한 줄 포지셔닝
> **"매일 아침 40분 걸리던 주문·택배 정리, 0분으로."**
> 스마트스토어·쿠팡 셀러 전용 업무 자동화. 써보고 결정하세요.

"AI 자동화", "n8n" 같은 말은 고객이 검색하지 않습니다. 고객이 쓰는 말로 파세요. **택배 엑셀, 송장, 주문 정리, 합포장, CS 답변**이 그 말입니다.

## 1. 누구에게 파나

| 구분 | 내용 |
|---|---|
| 핵심 타깃 | 스마트스토어·쿠팡 셀러, 1~5인 운영, 하루 주문 30~300건 |
| 왜 이 구간 | 30건 미만은 손으로 해도 버팀. 300건 넘으면 이미 유료 솔루션(이지어드민, 사방넷 등)을 씀. **그 사이가 빈 시장** |
| 아픈 곳 | 매일 아침 엑셀 정리, 택배 접수 실수(오배송), 같은 CS 답변 반복, 매출 파악 어려움 |
| 구매 결정 | 대부분 사장님 본인. "이거 하면 내가 몇 분 아끼나"로 판단 |
| 걱정 | "비싸지 않나", "고장 나면 어쩌나", "내 고객 정보 괜찮나" |

**페르소나 예시:** 잡곡·건강식품을 파는 40대 사장님. 직원 1명. 매일 9시에 주문 엑셀을 내려받아 택배 양식으로 옮기는 데 40분이 걸린다. 지난달 옵션을 잘못 옮겨 오배송이 3건 났다.

## 2. 판매 흐름 (퍼널)

```
[무료 택배 변환기]  →  [크몽 문의]  →  [15분 무료 진단]  →  [STANDARD/DELUXE 결제]  →  [월 유지보수·추가 자동화]
 써보고 "편하다"       "매일 자동으로     의뢰 처리 도구로      첫 납품, 리뷰            반복 매출
                       받고 싶어요"       견적·설계서 즉시
```

| 단계 | 도구 (이미 만든 것) | 목표 전환율 (초기 가정) |
|---|---|---|
| 방문 → 사용 | `docs/demo/` 무료 변환기 | 방문자의 30%가 파일 업로드 |
| 사용 → 문의 | 변환기 하단 "매일 자동으로 받기" | 사용자의 3~5% |
| 문의 → 견적 | `tools/intake.py` (24시간 안에 견적서·설계서) | 문의의 60% |
| 견적 → 결제 | 크몽 패키지 + 데모 화면 공유 | 견적의 30% |
| 결제 → 유지보수 | 납품 30일 후 유지보수 제안 | 고객의 30~40% |

> 전환율은 처음 한 달 실제 숫자로 바꿔 넣으세요. 어디서 새는지 보는 게 목적입니다.

**핵심 아이디어:** 무료 변환기 자체가 상품 시연입니다. 고객은 "손으로 하던 일이 버튼 하나로 된다"를 이미 경험한 상태로 문의합니다. 설득할 필요가 거의 없습니다.

## 3. 채널별 전략 (우선순위 순)

### ① 크몽 — 결제가 일어나는 곳
- 상세페이지: `docs/02_크몽_상세페이지_초안.md` 사용. 대표 이미지는 **엑셀 전/후 비교** (`docs/screenshots/05_택배엑셀_결과파일.png`)
- 서비스 제목에 고객 검색어 포함: "스마트스토어 택배 엑셀 자동화", "주문 정리 자동화"
- 포트폴리오에 스크린샷 5장 + 무료 변환기 링크
- **응답 속도가 순위에 영향**을 줍니다. 크몽 앱 알림을 켜고, 첫 답장은 1시간 안에. (`04_크몽_답장.txt`를 그대로 쓰면 5분)
- 첫 10건은 "오픈 기념가"로 STANDARD 99,000원 유지 → 리뷰 20개 이후 인상

### ② 네이버 블로그 — 검색으로 들어오는 사람
셀러들은 문제가 생기면 네이버에 검색합니다. 그 검색어로 글을 쓰고, 글마다 무료 변환기 링크를 답니다.

**제목 예시 (그대로 써도 됨)**
1. 스마트스토어 주문 엑셀 택배 양식으로 한 번에 바꾸는 법 (무료 도구)
2. 스마트스토어 합포장 자동으로 묶는 방법
3. 스마트스토어 주문 엑셀 비밀번호 푸는 법 + 택배 업로드까지
4. 쿠팡·스마트스토어 주문 한 엑셀로 합치기
5. 택배 오배송 줄이는 주문 정리 체크리스트
6. 1인 셀러 아침 업무 40분 → 5분 줄인 방법
7. 스마트스토어 문의 답변 AI로 초안 쓰기 (실제 사용기)
8. 스마트스토어 매일 매출 메일로 받는 법
9. CJ대한통운 업로드 양식 맞추는 법 (열 이름 정리)
10. 쇼핑몰 반복업무 자동화, 얼마 들까? (가격 비교)

**글 구조:** 문제 공감 (스크린샷) → 손으로 하는 법 (진짜 도움 되게) → "이걸 1초에" 무료 변환기 → "매일 자동으로 받으려면" 크몽 링크

주 2편, 4주면 8편. 블로그는 3개월 뒤부터 효과가 납니다. 일찍 시작하세요.

### ③ 셀러 커뮤니티 (네이버 카페·오픈채팅)
- **홍보 글을 올리지 말고 질문에 답하세요.** "택배 엑셀 정리 어떻게 하세요?" 같은 글에 방법을 설명하고, 마지막에 "제가 만든 무료 변환기도 있어요" 한 줄.
- 카페마다 홍보 규정이 있습니다. 홍보 게시판이 따로 있으면 거기만 씁니다. 규정 위반으로 강퇴되면 그 채널은 끝입니다.
- 무료 변환기는 "홍보"가 아니라 "도움"으로 받아들여집니다. 이게 이 전략의 핵심입니다.

### ④ 쇼츠·릴스 (유튜브 쇼츠, 인스타 릴스)
30초 전/후 영상이 가장 잘 먹힙니다. 대본 예시:

> (0~3초) "스마트스토어 사장님, 아침마다 이거 하시죠?" — 엑셀 복붙하는 화면
> (3~10초) "주문 50건, 택배 양식으로 옮기는 데 40분."
> (10~20초) 변환기에 파일 끌어다 놓기 → 결과 표 → 합포장·확인필요 표시
> (20~27초) "같은 집은 한 박스로, 주소 빠진 건 따로. 무료예요."
> (27~30초) "링크는 프로필에. 매일 자동으로 받고 싶으면 DM 말고 크몽으로."

화면 녹화만 있으면 됩니다. 얼굴 안 나와도 됩니다.

### ⑤ 지인·주변 셀러
- 첫 고객은 아는 사람에게서 나옵니다. 스마트스토어 하는 지인에게 무료 변환기를 보여주고 "이거 매일 자동으로 해줄까?"
- 크몽 밖에서 만난 고객은 크몽 밖에서 거래해도 됩니다. **반대로 크몽에서 만난 고객을 외부 결제로 유도하면 안 됩니다** (크몽 정책 위반, 계정 정지 위험).

## 5. 오퍼 (제안 방식)

- **무료:** 택배 변환기 (평생 무료, 가입 없음)
- **무료:** 15분 진단 (채팅으로 업무 듣고 "자동화하면 월 몇 시간 아끼는지" 계산 → `tools/intake.py` 견적서가 이걸 해줌)
- **STANDARD 99,000원:** 만들어 둔 워크플로 1개를 고객 계정에 세팅 (택배 엑셀 자동 생성이 가장 잘 팔릴 상품)
- **유지보수 월 55,000원:** "판매처가 엑셀 양식이나 API를 바꾸면 무료로 고쳐 드립니다" — 이게 실제로 자주 일어나는 일이라 설득력 있음

**가격 설득 문구:** "직원 시급 12,000원 × 하루 40분 × 월 26일 = 월 208,000원. 99,000원이면 2주 만에 회수됩니다."

## 7. 하지 말 것

- **대량 쪽지·DM, 카페 도배.** 단기 문의는 생겨도 평판이 망가지고, 우리가 거절하는 "스팸성 자동화"를 우리가 하는 셈입니다.
- **리뷰를 대가로 할인·환불 약속.** 크몽 정책 위반입니다. 할인은 "오픈 기념가"로만.
- **체험단 후기를 대가 표시 없이 게시.** 블로그 체험 후기를 받으면 "무료로 제공받아 작성" 표시가 필요합니다 (추천·보증 표시 지침).
- **"100% 자동", "절대 실수 없음" 같은 과장.** 취소 주문 확인 등 사람 확인 단계가 있다는 걸 솔직하게 쓰는 편이 신뢰를 줍니다.
- **고객 주문 데이터를 내 컴퓨터에 쌓아 두기.** 테스트가 끝나면 지우고, 고객 계정에서만 돌게 하세요.

## 부록: 무료 변환기 공개하는 법 (GitHub Pages)

1. GitHub 저장소 → **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: `kmong-portfolio`, 폴더: `/docs` → Save
3. 1~2분 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/demo/` 에서 열림
4. `docs/demo/tool.html` 맨 아래 스크립트의 `KMONG_URL`, `CONTACT`를 내 크몽 주소로 바꾸고, `python3 docs/demo/build_page.py`로 `index.html`을 다시 만든 뒤 커밋

> 저장소 이름이 `-`라서 주소가 어색합니다. 마케팅용이면 `seller-tools` 같은 이름의 새 저장소를 만들어 옮기는 것을 권합니다.
