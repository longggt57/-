# 업무 자동화 요구사항 인터뷰 질문지

> 사용법: 첫 상담 때 고객에게 이 순서대로 묻고, 답을 그대로 적어 Claude에게 넘기면 설계서와 견적이 바로 나옵니다.
> 고객이 답을 모르면 "화면 녹화 1~2분"만 받아도 충분합니다.

---

## A. 문제 (PROBLEM) — 지금 무엇이 힘든가

1. 자동화하고 싶은 업무를 한 문장으로 말씀해 주세요.
   - 예: "스마트스토어 주문을 매일 아침 엑셀로 옮겨서 택배사에 올린다"
2. 이 업무를 **누가**, **얼마나 자주**, **한 번에 몇 분** 하나요?
   - 담당자: ____ / 빈도: 하루 __회 · 주 __회 / 1회 소요: __분
3. 이 업무에서 가장 자주 생기는 실수나 사고는 무엇인가요?
4. 이 업무가 하루 밀리면 어떤 문제가 생기나요? (배송 지연, 고객 불만, 매출 누락 등)

## B. 이유 (WHY) — 왜 지금 해결하려 하나

5. 지금 자동화를 알아보시게 된 계기가 있나요? (주문 증가, 직원 퇴사, 실수 발생 등)
6. 자동화가 성공했다고 판단할 기준은 무엇인가요?
   - 예: "담당자가 이 업무에 손을 안 댄다", "실수 0건", "아침 9시 전에 끝나 있다"

## C. 방법 (HOW) — 지금 쓰는 도구와 데이터

7. 이 업무에서 쓰는 사이트·프로그램을 전부 적어 주세요.
   - [ ] 네이버 스마트스토어 [ ] 쿠팡 Wing [ ] 카페24 [ ] 자사몰
   - [ ] 구글 시트 [ ] 엑셀 파일 [ ] 사내 ERP/그룹웨어: ____
   - [ ] 슬랙 [ ] 카카오톡 [ ] 이메일(Gmail/네이버/기타) [ ] 문자
   - [ ] 기타: ____
8. 위 도구 중 **API 키를 발급받을 수 있는 것**이 있나요? (모르면 "모름" — 저희가 확인합니다)
9. 입력 데이터 샘플과 원하는 결과물 샘플을 보내주실 수 있나요? (개인정보는 가려도 됩니다)
10. 사람이 판단해야 하는 단계가 있나요? (예: "금액이 50만 원 넘으면 사장님 확인")

## D. 결과 (SO WHAT) — 끝나면 무엇을 받고 싶은가

11. 결과를 **어디서** 받고 싶으세요? (슬랙 알림 / 카톡 / 메일 / 구글시트 / 엑셀 파일)
12. 결과를 **언제** 받고 싶으세요? (실시간 / 매시간 / 매일 아침 __시)
13. 오류가 나면 누구에게 알려야 하나요?

## E. 사용자 (WHO) — 누가 쓰고 누가 고치나

14. 완성된 자동화를 실제로 쓸 분은 누구인가요? (IT 이해도: 상 / 중 / 하)
15. 나중에 간단한 수정(문구, 수신자, 시간)은 직접 하고 싶으신가요, 맡기고 싶으신가요?
16. 서버는 어떻게 하시겠어요?
   - [ ] n8n Cloud 구독 (월 약 3~5만 원, 관리 불필요)
   - [ ] 저희가 대신 세팅한 서버 (월 유지보수 계약)
   - [ ] 사내 서버 / 이미 쓰는 n8n

## F. 일정·예산

17. 언제까지 필요하신가요?
18. 생각하신 예산 범위가 있나요? (35만 / 88만 / 150만 / 협의)

## 상담 후 내부 정리 (판매자용)

| 항목 | 내용 |
|---|---|
| 절감 시간 | 하루 __분 × 월 __일 = 월 __시간 |
| 절감 금액(인건비 시급 1.2만 원 가정) | 월 ______원 → **견적 근거로 고객에게 제시** |
| 연동 대상 / API 가능 여부 | |
| 사람 승인 단계 | |
| 위험 요소 | 약관 위반 소지(매크로·SNS 자동화), 개인정보, 로그인 2차 인증 |
| 추천 패키지 | STANDARD / DELUXE / PREMIUM |

### 받지 않는 의뢰 (거절 기준)
- 티켓·공연 예매 매크로 (공연법 위반)
- 카카오톡·인스타그램 등 SNS 계정 대량 자동화 (계정 정지 위험, 약관 위반)
- 타인 사이트 대량 크롤링으로 서비스에 부하를 주는 작업
- 고객이 정당한 권한을 가지지 않은 계정·데이터 접근
