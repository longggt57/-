## 본문

### 이런 분께 필요합니다
- 아침마다 스마트스토어·쿠팡 주문을 엑셀로 옮기고 계신 분
- 고객 문의에 같은 답을 매일 반복해서 쓰고 계신 분
- 어제 매출이 얼마인지 보려면 여러 사이트를 열어야 하는 분
- 직원에게 맡기자니 실수가 걱정되는 분

### 실제로 만들어 드린 자동화 (포트폴리오)

**① 신규 주문 → 구글시트 자동 기록 → 슬랙 알림**
10분마다 새 결제 주문을 가져와 시트에 정리하고, 몇 건·얼마인지 슬랙으로 알려드립니다. 같은 주문은 두 번 기록되지 않습니다.

**② 고객 문의 AI 분류 + 답변 초안**
문의가 들어오면 AI가 배송/교환/상품/불만으로 분류하고, 우리 가게 정책에 맞는 답변 초안을 작성해 슬랙으로 보내드립니다. 불만·긴급 건은 사람 확인 요청으로 따로 표시합니다. **AI가 고객에게 바로 보내지 않습니다.** 사장님이 확인 후 복사만 하시면 됩니다.

**③ 매일 아침 매출 리포트**
매일 오전 8시 30분, 어제 매출·주문수·인기상품 TOP5·지난주 같은 요일 대비 증감을 슬랙과 메일로 보내드립니다. AI가 한 줄 코멘트도 달아드립니다.

### 다른 곳과 다른 점
- **AI 프롬프트까지 저희가 설계합니다.** "프롬프트는 고객님이 준비하세요"라고 하지 않습니다. 가게 정책을 알려주시면 답변 품질까지 맞춰 드립니다.
- **설계서를 먼저 보여드리고 만듭니다.** 확인 전에는 작업을 시작하지 않습니다.
- **고객님 소유입니다.** 완성된 워크플로 파일을 그대로 드립니다. 다른 업체로 옮기셔도 됩니다.
- **수정 쉬운 구조.** 알림 받을 채널, 시간, 문구는 맨 앞 '설정' 칸 하나만 바꾸면 됩니다.

### 진행 순서
1. 채팅 상담 (화면 녹화 1~2분이면 충분합니다)
2. 설계서 + 견적 전달
3. 결제 후 제작
4. 고객님 계정으로 연결 테스트 (원격 또는 가이드 제공)
5. 사용 가이드 전달, 30일 무상 오류 대응

## FAQ

**Q. 코딩을 전혀 모르는데 쓸 수 있나요?**
네. 완성 후에는 손댈 일이 없고, 바꿀 만한 부분(알림 채널, 시간, 문구)은 '설정' 칸에 모아 두었습니다.

**Q. AI가 고객에게 이상한 답을 보내면 어떡하나요?**
기본 설정은 AI가 **초안만** 만들고 사람이 확인 후 보냅니다. 불만·환불 문의는 자동으로 '사람 확인 필요'로 분류됩니다.

**Q. 스마트스토어 API는 어떻게 받나요?**
커머스API센터에서 애플리케이션을 등록하면 됩니다. 발급 화면을 같이 보면서 안내해 드립니다.

**Q. 월 비용이 계속 드나요?**
제작비는 1회입니다. n8n 실행 비용(직접 서버 또는 Cloud 구독)과 AI 사용료만 고객님 계정에서 발생합니다.
