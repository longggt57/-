# 자동화 설계서 — 잡곡 판매 업체

> 스마트스토어·쿠팡 주문 통합 → 구글시트 정리 → CJ대한통운 업로드 파일 생성 → 슬랙 알림 (송장 등록은 2단계)

## 흐름도
```mermaid
flowchart LR
  S0["매일 08:40 실행"]
  S1["스마트스토어 주문 조회"]
  S0 --> S1
  S2["쿠팡 주문 조회"]
  S1 --> S2
  S3["주문 통합·정리"]
  S2 --> S3
  S4{"이상 주문 있음?"}
  S3 --> S4
  S5["주문 시트 기록"]
  S4 --> S5
  S6["택배 업로드 파일 생성"]
  S5 --> S6
  S7["택배 시트 기록"]
  S6 --> S7
  S8["처리 결과 알림"]
  S7 --> S8
```

## 단계별 동작
| # | 종류 | 단계 | 서비스 | 설명 |
|---|---|---|---|---|
| 1 | ⏰ 예약 실행 | **매일 08:40 실행** | - | 출고일(월~토) 오전 8시 40분에 자동 실행합니다. |
| 2 | 🔗 외부 연동 | **스마트스토어 주문 조회** | 네이버 스마트스토어 | 전일 출고 마감 이후 결제완료된 주문을 커머스 API로 가져옵니다. |
| 3 | 🔗 외부 연동 | **쿠팡 주문 조회** | 쿠팡 Wing | 같은 기간 결제완료(ACCEPT) 상태의 쿠팡 주문을 가져옵니다. |
| 4 | ⚙ 데이터 처리 | **주문 통합·정리** | - | 두 판매처 주문을 같은 열 구조로 맞추고, 판매처·옵션·주소를 정규화합니다. 주소 누락이나 옵션 불일치는 '확인필요'로 표시합니다. |
| 5 | 🔀 조건 분기 | **이상 주문 있음?** | - | '확인필요'로 표시된 주문이 있으면 담당자 확인 알림을 먼저 보냅니다. |
| 6 | 📝 시트 기록 | **주문 시트 기록** | 구글시트 | 통합된 주문을 구글시트 '주문' 탭에 날짜별로 기록합니다. |
| 7 | ⚙ 데이터 처리 | **택배 업로드 파일 생성** | CJ대한통운 | CJ대한통운 업로드 양식 열 순서에 맞춘 파일 데이터를 만들고 시트 '택배업로드' 탭에 씁니다. |
| 8 | 📝 시트 기록 | **택배 시트 기록** | 구글시트 | 업로드용 데이터를 '택배업로드' 탭에 기록해 바로 내려받을 수 있게 합니다. |
| 9 | 💬 슬랙 알림 | **처리 결과 알림** | 슬랙 | 판매처별 주문 건수, 확인필요 건수, 시트 링크를 슬랙으로 보냅니다. |

## 사람이 확인하는 지점
- 주소 누락·옵션 불일치로 '확인필요' 표시된 주문 검토
- 택배 업로드 파일을 CJ대한통운에 올리기 전 최종 확인

## 이렇게 되면 성공입니다
- 매일 아침 출고 준비(주문 통합 + 택배 파일 생성)를 사람 손 없이 끝내기
- 옵션·주소 옮겨 적기 실수로 인한 오배송 0건
- 처리 결과를 슬랙으로 바로 확인
- (2단계) 송장번호를 판매처에 자동 등록

## 알아두실 점
- 쿠팡 Open API는 HMAC 서명이 필요해 키 발급과 테스트 시간이 추가로 듭니다.
- CJ대한통운 API 연동은 계약 조건 확인이 필요합니다. 1단계에서는 업로드 파일 생성까지만 자동화합니다.
- 수령인 이름·연락처·주소 등 개인정보를 구글시트에 저장하므로 시트 공유 범위를 제한해야 합니다.
- 송장 자동 등록(2단계)은 택배사에서 송장번호를 받아오는 방식이 정해져야 범위를 확정할 수 있습니다.
