## 포함 범위
1. 매일 08:40 실행 — 출고일(월~토) 오전 8시 40분에 자동 실행합니다.
2. 스마트스토어 주문 조회 — 전일 출고 마감 이후 결제완료된 주문을 커머스 API로 가져옵니다.
3. 쿠팡 주문 조회 — 같은 기간 결제완료(ACCEPT) 상태의 쿠팡 주문을 가져옵니다.
4. 주문 통합·정리 — 두 판매처 주문을 같은 열 구조로 맞추고, 판매처·옵션·주소를 정규화합니다. 주소 누락이나 옵션 불일치는 '확인필요'로 표시합니다.
5. 이상 주문 있음? — '확인필요'로 표시된 주문이 있으면 담당자 확인 알림을 먼저 보냅니다.
6. 주문 시트 기록 — 통합된 주문을 구글시트 '주문' 탭에 날짜별로 기록합니다.
7. 택배 업로드 파일 생성 — CJ대한통운 업로드 양식 열 순서에 맞춘 파일 데이터를 만들고 시트 '택배업로드' 탭에 씁니다.
8. 택배 시트 기록 — 업로드용 데이터를 '택배업로드' 탭에 기록해 바로 내려받을 수 있게 합니다.
9. 처리 결과 알림 — 판매처별 주문 건수, 확인필요 건수, 시트 링크를 슬랙으로 보냅니다.

- 연동 서비스 자체 이용료, AI(Claude) API 사용료 (고객님 계정에서 사용량만큼 발생)

- 납품 후 판매처·사이트 정책 변경 대응 — 월 유지보수 옵션 55,000원/월
