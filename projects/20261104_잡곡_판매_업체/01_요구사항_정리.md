# 요구사항 정리 (내부용) — 잡곡 판매 업체

> 스마트스토어·쿠팡 주문 통합 → 구글시트 정리 → CJ대한통운 업로드 파일 생성 → 슬랙 알림 (송장 등록은 2단계)

## PROBLEM — 문제
직원이 매일 두 판매처 주문 엑셀을 수작업으로 합치고 택배 양식으로 재정리하느라 약 40분이 들고, 옵션·주소 혼동으로 오배송이 발생합니다. 송장번호를 판매처에 다시 입력하는 데도 약 20분이 걸립니다.

## WHY — 지금 해결하려는 이유
하루 40~60건으로 수작업 부담과 오배송 위험이 커진 상태 (추정)

## 성공 기준
- 매일 아침 출고 준비(주문 통합 + 택배 파일 생성)를 사람 손 없이 끝내기
- 옵션·주소 옮겨 적기 실수로 인한 오배송 0건
- 처리 결과를 슬랙으로 바로 확인
- (2단계) 송장번호를 판매처에 자동 등록

## 현재 수작업 순서
1. 스마트스토어 판매자센터에서 신규 주문 엑셀 다운로드
2. 쿠팡 Wing에서 신규 주문 엑셀 다운로드
3. 두 파일을 하나로 합치고 열 순서 정리
4. CJ대한통운 업로드 양식에 맞게 수령인·주소·상품·옵션 재입력
5. 택배 접수 후 송장번호를 각 판매처에 하나씩 입력

## 연동 서비스
| 서비스 | API | 메모 |
|---|---|---|
| 네이버 스마트스토어 | 가능 | 커머스API센터에서 애플리케이션 등록 후 주문 조회·발송 처리 API 사용 |
| 쿠팡 Wing | 가능 | Wing 판매자센터에서 Open API 키 발급 (HMAC 서명 필요) |
| 구글시트 | 가능 | n8n 기본 Google OAuth 연결 |
| CJ대한통운 | 확인필요 | 계약 형태에 따라 API 연동 가능 여부가 다름. 우선 업로드용 엑셀 파일 생성으로 대응 |
| 슬랙 | 가능 | n8n 기본 Slack 연결 |

## 사람 확인 지점
- 주소 누락·옵션 불일치로 '확인필요' 표시된 주문 검토
- 택배 업로드 파일을 CJ대한통운에 올리기 전 최종 확인

## 위험 요소
- 쿠팡 Open API는 HMAC 서명이 필요해 키 발급과 테스트 시간이 추가로 듭니다.
- CJ대한통운 API 연동은 계약 조건 확인이 필요합니다. 1단계에서는 업로드 파일 생성까지만 자동화합니다.
- 수령인 이름·연락처·주소 등 개인정보를 구글시트에 저장하므로 시트 공유 범위를 제한해야 합니다.
- 송장 자동 등록(2단계)은 택배사에서 송장번호를 받아오는 방식이 정해져야 범위를 확정할 수 있습니다.

## 견적 전 확인 질문
1. 스마트스토어 커머스API, 쿠팡 Wing Open API 키를 발급받으실 수 있나요? (발급 방법은 안내드립니다)
2. 현재 쓰시는 CJ대한통운 업로드 양식 파일을 보내주실 수 있나요?
3. 출고 마감 시간이 몇 시인가요? (어느 시점까지의 주문을 당일 출고로 볼지)
4. 송장번호는 지금 어디서 확인하시나요? (택배사 사이트 엑셀 다운로드 / 문자 등)
5. 알림 받을 슬랙 워크스페이스가 있으신가요? 없으면 메일로도 가능합니다.

## 판정
- 난이도: **보통** · 단계 9개 · 연동 5개 (CJ대한통운, 구글시트, 네이버 스마트스토어, 슬랙, 쿠팡 Wing)
- 추천 패키지: **PREMIUM** (770,000원)
- 절감 추정: 1회 60분 × 월 26회 = **월 26.0시간** ≈ 312,000원 (시급 12,000원 기준)
